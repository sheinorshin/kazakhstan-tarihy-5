# Қазақстан тарихы · 5-сынып

«Қазақстан тарихы» оқулығы (5-сынып, 1-бөлім; С.Р. Ахметова, А.М. Ибраева, А.А. Құлымбетова,
А.С. Мағзұмова, А.М. Марқабаева, 2017) негізіндегі оқушылар мен мұғалімдерге арналған сайт.

**Сайтты жасаған:** Аусулу Карабаева

## Бөлімдері

- **Тақырыптар** — 7 тарау, 32 тақырып: қысқаша мазмұны, кілт сөздер, дереккөздер, даталар,
  тақырыптағы тұлғалар, мұғалімге арналған мақсаттар мен тапсырмалар, «Өзіңді тексер» тесті.
- **Тұлғалар** — 74 тұлға туған жылы бойынша; әрқайсысының өмір сүрген жылдары, шыққан жері,
  істері, туыстары және қай тақырыпта аталатыны (сілтемелермен).
- **Уақыт өзені** — дәуірлер мен оқиғалар, ғалымдардың ашулары.
- **Тарихи карта** — ескерткіштер мен тайпа мекендері.
- **Сөздік** — терминдер түсіндірмесі.
- **Сайыс** — тест және «Кім айтты?» ойыны.

## Мәтінді өзгерту

Барлық мәтін `assets/` ішіндегі деректер файлдарында:

| Файл | Мазмұны |
|---|---|
| `data-1.js` | Кітап, авторлар, тараулар, кіріспе және 1-тарау |
| `data-2.js` | 2 және 3-тараулар |
| `data-3.js` | 4, 5, 6, 7-тараулар |
| `data-4.js` | Тұлғалар |
| `data-5.js` | Сөздік, карта, уақыт сызығы |

Тек тырнақшадағы мәтінді өзгертіңіз, тырнақша мен үтірлерді өшірмеңіз.

## GitHub Pages-ке жариялау

1. GitHub-та жаңа репозиторий ашыңыз, осы папкадағы барлық файлды (`index.html`, `assets/`) жүктеңіз.
2. **Settings → Pages → Branch: `main` / `(root)` → Save**.
3. Бір-екі минуттан кейін сайт `https://<аккаунт>.github.io/<репозиторий>/` мекенжайында ашылады.

Тұлғалардың суреттері Wikimedia Commons-тан интернет арқылы жүктеледі (әр суреттің авторлық
сілтемесі тұлға терезесінде бар). Интернет болмаса, сурет орнына аты-жөнінің бас әріптері шығады.
